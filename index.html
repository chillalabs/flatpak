2fip

A keyboard-driven, dual-pane file manager for COSMIC, inspired by Total Commander.

Install

Install with Flatpak

Or in a terminal:

flatpak install --user https://chillalabs.github.io/flatpak/2fip.flatpakref

Updates come with flatpak update. The runtime is installed from Flathub automatically.

Add the repository

flatpak remote-add --user --if-not-exists chillalabs https://chillalabs.github.io/flatpak/chillalabs.flatpakrepo
Signed with the key chillalabs.gpg (fingerprint B8DB 59C9 D8DE 325B ED44 7464 D0A0 9A1D 8E8E DB64).
